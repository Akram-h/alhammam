الهمام — إصدار Android مستقل يعمل دون إنترنت
============================================

ما الذي يقدمه هذا المشروع؟
- تطبيق Android مستقل، لا يحتاج إلى موقع أو خادم أو تسجيل دخول.
- ملفات التطبيق وواجهته مضمّنة داخله، لذلك يعمل دون اتصال بالإنترنت بعد التثبيت.
- حفظ تلقائي محلي للبطاقات والصور والإعدادات باستخدام IndexedDB داخل مساحة التطبيق.
- نسخ احتياطي واستعادة إلى ملف JSON من داخل التطبيق.
- اختيار الصور من الهاتف، وتصدير PDF والصور، والطباعة عبر نظام Android.
- لا توجد صلاحية INTERNET في AndroidManifest؛ التطبيق لا يطلب الاتصال بالإنترنت.

طريقة إنشاء APK على Windows:
1. ثبّت Android Studio من الموقع الرسمي، وافتحه مرة واحدة لإعداد Android SDK.
2. فك ضغط مجلد Alhammam-Android.
3. من Android Studio اختر Open ثم اختر مجلد Alhammam-Android نفسه.
4. انتظر انتهاء Gradle Sync. يلزم اتصال إنترنت لمرة واحدة لتنزيل أدوات البناء والمكتبات فقط.
5. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
6. بعد اكتمال البناء اختر Locate. ملف التثبيت يكون عادةً:
   app\build\outputs\apk\debug\app-debug.apk
7. انقل APK إلى الهاتف وثبّته. بعد التثبيت لا يحتاج التطبيق إلى الإنترنت.

ملاحظات مهمة:
- لا يمكن ضمان الاحتفاظ بالبيانات إذا حُذف التطبيق أو مُسحت بياناته؛ صدّر نسخة احتياطية دورية واحفظها خارج الهاتف.
- النسخ الاحتياطي لا يرفع أي بيانات إلى الإنترنت؛ أنت تختار مكان حفظ ملف JSON.
- ملف APK الناتج من Build APK(s) هو نسخة Debug للتجربة والتثبيت الشخصي. للنشر العام أنشئ Signed APK من Build > Generate Signed Bundle / APK.
- رقم الحزمة: com.alhammam.app
- الحد الأدنى: Android 6.0 (API 23)

الأمان والخصوصية:
لا يحتوي المشروع على مفتاح تفعيل أو اشتراك أو اتصال بخادم. لا توجد آلية انتهاء صلاحية مبرمجة.
