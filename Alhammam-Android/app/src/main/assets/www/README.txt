الهمام — تطبيق قابل للتثبيت (موبايل + حاسبة)
=============================================

1) ارفع محتويات هذا المجلد (الملفات نفسها) على استضافة HTTPS مجانية، مثل:
   Netlify Drop (app.netlify.com/drop: اسحب المجلد)، أو GitHub Pages، أو Cloudflare Pages.
2) افتح الرابط ثم ثبّته:
   - أندرويد (Chrome): القائمة ⋮ ← تثبيت التطبيق (Install app)
   - ويندوز / ماك (Chrome أو Edge): أيقونة التثبيت في شريط العنوان
   - آيفون (Safari): مشاركة ← إضافة إلى الشاشة الرئيسية
3) بعد التثبيت يظهر كتطبيق بأيقونته ويعمل بدون إنترنت.
4) للحصول على ملف APK حقيقي: افتح pwabuilder.com وضع رابط تطبيقك واختر Android.

الخصوصية: الصور تُعالَج داخل الجهاز ولا تُرفع لأي مكان.
